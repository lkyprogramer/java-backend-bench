# 可重复的模型比较协议

## 1. 模型与 Agent 不能混为一谈

本题测的是“模型 + 量化 + 推理后端 + Agent + 工具/上下文策略 + 预算”这一运行配置的交付结果。必须记录完整 served model ID、可取得的权重/量化标识、引擎版本、temperature/top_p/seed、上下文窗口、推理强度、Agent/版本、系统提示词、工具权限和上下文压缩配置。

同名 Qwen 模型的不同 GGUF/AWQ、不同推理强度、不同 cache/compaction 配置必须分开标注。不能把一个 Agent 的优势归因于另一个模型。使用 Pi 时，固定 Pi 版本及 sol-pi/其他上下文插件的开关和版本；不要在两模型之间顺便更换 Agent 或压缩策略。

## 2. 推荐第一次实验

先各跑一次完整流程校验材料能工作，再固定一个预算（示例 180 分钟）进行正式实验。条件不够时，至少诚实地标注 n=1；不要用一份源码重复评测伪造三次模型开发。

正式比较建议每种配置 3 次从全新工作区、全新对话独立生成；重要判断建议 5 次。每次只拿相同起始包、相同提示词、相同预算和工具，不共享前次方案/缓存出来的答案/其他模型源码。允许模型跑公开 smoke 和自身测试；不允许在冻结前查看隐藏裁判反馈。

测试种子可在整组实验前由操作者固定，例如 1701、1702、1703，并成对应用到两个模型的第 1/2/3 次。隐藏种子不能交给模型。保留首次交付快照，无论成功失败都计入。

推理生成随机种子和裁判状态机种子是不同字段。服务的手动时钟不是模型随机种子。不要将同一个 seed 配置误认为能够保证 GPU 推理/并发调度完全确定。

## 3. 隔离比较目标

**工程质量比较**：代码冻结后在同一 CPU/内存/磁盘/JDK/Python 环境评分，停止争抢资源的模型推理，使用同一校准。GPU/本地 LLM 生成吞吐不在 D09 里面。

**完成效率比较**：另记录真实开发 wall seconds、输入/输出 token、工具调用次数、编译/测试迭代、人工干预。原始数据存在 metadata.generation_metrics；缺失填 null，不能从代码行数、评测时长或模型参数量估算。

固定时间预算是主条件；固定 token 预算、固定推理强度或不同量化可以作为独立实验，不与主条件混合。更快完成但功能差，和更慢完成但正确，是两条轴，不硬凑单一速度冠军。

## 4. 时间采集

`tools/time_agent.py` 可包装你的实际 Agent 命令，只采集进程墙钟、退出码和 stdout/stderr，不会猜 token 或修改 Agent 配置：

```bash
python3 tools/time_agent.py \
  --cwd ../work/qwen27b-r1 \
  --out ../records/qwen27b-r1-timing \
  --timeout 10800 --allow-exec -- <your-agent> <its-arguments>
```

尖括号表示替换成你实际使用的命令，工具不会凭空知道 Pi/Codex 的 provider 设置。也可以用交互式 Agent，人工记录开始/结束和干预次数，明确来源为 operator_recorded。

`evaluation_seconds` 是裁判运行时间，不能当作开发时间。模型中途报告“完成”后应立即冻结，不额外由人修复再当原始输出。

## 5. 多次结果

使用 compare 输出每维均值、总分均值/中位数/范围/标准差与关键门槛通过比例，优先看稳定性与失败类型。bootstrap 区间是对少数尝试的描述性重采样，n=3 非常不稳定，不能证明普遍显著性。单题的置信区间也不能代替跨任务的泛化区间。

同一题没有覆盖整个 Java 工程领域。需要通用模型排序时增加独立题目：既有项目定位修复、兼容性变更、SQL/事务、真实框架、小型性能故障定位等，而不是把本题复制十遍只换商品名字。

## 6. 泄漏与版本

公开标准完整、测试数据隐藏。不要给考生 reference、judge、既往隐藏报告、变异源码。模型曾见过参考解应标注 contaminated，不能再当盲测。

换种子增加组合覆盖但不能彻底防过拟合；相同语义的模板题重复得太多会变成记忆测验。题目/错误码/评分/工作负载变化必须升级 benchmark_version。仅修正文案错字可补丁升级并注明是否影响判题。旧、新版本分数不要直接合并。

保留：题目 SHA、裁判 SHA、候选源码 SHA、时间记录、模型/Agent 元数据、独立运行 ID、全部失败尝试、完整报告与机器环境。不要只保留最好一轮或只报平均分。

计时工具把完整 stdout/stderr 保存为 `agent.log`，可能包含业务资料或令牌回显；分享前自行检查。默认只记录命令可执行文件和参数 SHA，不记录完整参数；显式 `--record-argv` 才保存参数，参数里不要包含密钥。工具继承你的现有 Agent 环境，不会加载或替换模型设置；超时返回 124，且尝试清理同进程组。独立会话/逃逸子进程不属于强隔离保证。

计时结果中的 wall_seconds 可复制到模型元数据 `generation_metrics.wall_seconds`，标明采集来源；开始/结束时间写入 generation。token/工具次数继续使用后端或 Agent 的真实日志，不因有计时结果而补猜。
