# Reference design

Main 负责精确路由、HTTP/JSON 边界、权限与错误封装；Service 负责业务状态、单事务锁、幂等指纹、截止时间堆、事件 schema 与重放。Journal 是提供的冻结原语，不是模型需要手写的数据库。

商品查询为期望 O(1)，成功幂等查找为期望 O(1)，预占记录有序写入 O(log N)，过期堆处理 O(E log N)，列表按 ID 范围扫描并过滤，统计 O(N)。全局同步牺牲极高写并发吞吐，换取小项目的清晰原子边界；这里不把它包装成生产高可用系统。

事件先 append/force，成功后更新内存。重放使用历史事件时间；全部历史恢复完成后才应用启动时钟并清理到期 ACTIVE，避免已确认的历史记录被重复释放。没有实现日志压缩、多进程读写、跨机复制、磁盘满的全面注入或断电测试。
