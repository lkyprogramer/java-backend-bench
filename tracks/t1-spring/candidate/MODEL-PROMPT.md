你需要完成当前工作目录中的 ReserveLedger-Spring 后端项目（Spring Boot 3.5 + Spring Data JPA + Flyway + H2，Java 21）。

请先阅读 TASK.md 和 AGENTS.md，按照其中完整契约实现源码、Flyway 迁移、JUnit 黑盒契约测试、README.md、DESIGN.md、TESTING.md。只使用冻结 pom 中的依赖，Maven 只能离线构建。你可以自主规划、编译、运行服务和自己的测试，并根据这些反馈修复问题。

优先保证：业务正确、库存守恒、幂等、并发原子性、事务边界、过期边界、持久化恢复，以及真实有效的测试。不要只给方案，要把可执行代码写入当前工作区。不得修改冻结文件或降低规范，不得读取其他工作区/裁判/参考实现，不得调用网络或寻求额外人工帮助。

时间预算以操作者事先冻结的本轮配置为准。尽量在预算内完成；未完成时保留真实进展，不伪造测试结果。最终简要说明已实现范围、实际执行的测试和已知限制。
